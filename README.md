# noRender

noRender is a lightweight rendering library built on OpenGL. It wraps common setup and drawing tasks so new projects can get started without repeating OpenGL boilerplate. It is inspired by [raylib](https://www.raylib.com/).

It supports basic 2D and 3D rendering and is used by [robot_learns_to_walk](https://github.com/NobodyBuilds/robot_learns_to_walk) and [deep_reinforcement_learning](https://github.com/NobodyBuilds/deep_reinforcement_learning).

## Documentation

See [documentation.md](documentation.md) for setup instructions, rendering examples, and the API guide.

## Development

noRender is maintained alongside the projects that use it. Updates are occasional and are generally driven by rendering features needed in another project.
